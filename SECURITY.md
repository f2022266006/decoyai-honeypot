# Security Policy

Use DecoyAI only as a localhost educational laboratory. Do not remove its
loopback binding controls or expose it through tunnels, routers, cloud hosts, or
port forwarding without a separate authorized security design and review.

Never submit real secrets or personal data. Delete `data/decoyai.db` to remove
recorded laboratory interactions.

Report vulnerabilities privately to the maintainer with reproduction steps,
impact, and a suggested mitigation where possible.
